# Web development labs

A learning roadmap for WordPress, Java and web hosting. Each exercise is planned. Add evidence after reproducing the result.

| Exercise | Status | Evidence to add |
| --- | --- | --- |
| WordPress child theme | Planned | Theme changes, local setup steps and a keyboard navigation check. |
| Java command-line input handling | Planned | Source code and example runs for valid, empty and rejected inputs. |
| Local backup and restore | Planned | Restore checklist, elapsed time and a comparison of pages and media. |

## WordPress

Create a local site for a fictional community event. Add one page and one post. Change the presentation in a child theme and record the steps to reproduce it.

## Java

Build a command-line tool that totals positive quantities. Separate input parsing from calculation and test both valid and invalid input.

## Web hosting

Back up the database and site files of a disposable site. Restore them into a separate local environment and verify that the pages and media match. Use synthetic data and keep credentials and backups local.
